# Dynamic Programming
- Solving Complex Probvlems into smaller overlapping sub problems and storing their data in the result.
- Programming method where we revisit prev call if there is no further
- Choose->Explore->Undo->Try Another
    # Types of DP
    1. Tabulation(Bottom-Up):
      - Uses for Loop
      - Iterate and Stores the data in table
    2. Memoization(Top-down):
    - Using Recursion call stack poped values
    - Stores answer
